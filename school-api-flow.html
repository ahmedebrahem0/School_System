🔄 School System API — ترتيب الاعتماديات (Flow)

1
المرحلة الأولى — Authentication (لازم تبدأ بيها)
⚠️ كل الـ endpoints التانية محتاجة Token — لازم تعمل Login الأول وتحفظ الـ token
POST
/api/Auth/Register
تسجيل يوزر جديد (Student / Teacher)
↓
POST
/api/Auth/Login
تسجيل دخول → بيرجع token احفظه في متغير
↓
2
المرحلة التانية — Admin: تعيين الأدوار
يحتاج: Token من Admin account — بعد Register لازم Admin يعين الدور
GET
/api/Admin/users-without-role
جيب اليوزرز اللي معندهمش role عشان تعرف مين تعين ليه
↓
POST
/api/Admin/assign-role
عين role للـ user (Student / Teacher)
يحتاج userId
↓
3
المرحلة التالتة — إنشاء المواد (Subjects)
يحتاج: Token — Classes بتحتاج Subjects موجودة قبلها
POST
/api/Subjects
أنشئ مادة دراسية جديدة → بيرجع subjectId
↓
GET
/api/Subjects
جيب كل المواد وخد الـ IDs
GET
/api/Subjects/:id
تفاصيل مادة معينة
يحتاج subjectId
↓
4
المرحلة الرابعة — إنشاء الفصول (Classes) والغرف (Classrooms)
يحتاج: Subjects موجودة — Students وTeacherClasses بتحتاج Classes
POST
/api/Classroomes
أنشئ غرفة/فصل فيزيائي → بيرجع classroomId
↓
POST
/api/Classes
أنشئ Class (الفصل الدراسي) → بيرجع classId
يحتاج classroomId
↓
GET
/api/Classes
جيب كل الـ Classes وخد الـ IDs
GET
/api/Classes/InFormation/:ClassId
تفاصيل كاملة عن الـ Class (Teachers + Students)
يحتاج classId
↓
5
المرحلة الخامسة — إضافة المدرسين (Teachers)
يحتاج: Token + userId من Register + Classes موجودة
POST
/api/Teachers
أنشئ Teacher profile → بيرجع teacherId
يحتاج userId
↓
POST
/api/TeacherClasses
اربط المدرس بالـ Class
يحتاج teacherId + classId
GET
/api/TeacherClasses/Teacher/:teacherId
جيب كل الـ Classes بتاعت مدرس معين
يحتاج teacherId
GET
/api/Teachers/TeacherDetails/:id
تفاصيل كاملة عن المدرس
يحتاج teacherId
↓
6
المرحلة السادسة — إضافة الطلاب (Students)
يحتاج: Token + userId + Classes موجودة
POST
/api/Students
أنشئ Student profile → بيرجع studentId
يحتاج userId + classId
GET
/api/Students/MyProfile
بروفايل الطالب الحالي (من الـ token)
GET
/api/Students/attendance
حضور طالب معين بالاسم
يحتاج studentName
↓
7
المرحلة السابعة — الدرجات (Grades)
يحتاج: Students + Classes + Subjects كلها موجودة
POST
/api/Grades
أضف درجة لطالب في مادة
يحتاج studentId + subjectId
GET
/api/Grades/Student/:name
جيب درجات طالب باسمه
يحتاج studentName
GET
/api/Grades/MyGrades
درجات الطالب الحالي (من الـ token)
↓
8
المرحلة الثامنة — الحضور (Attendances)
يحتاج: Students + Classes موجودة
POST
/api/Attendances
سجل حضور طالب
يحتاج studentId + classId
GET
/api/Attendances
جيب كل سجلات الحضور
GET
/api/Attendances/:id
تفاصيل سجل حضور معين
يحتاج attendanceId
